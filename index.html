My app build rules

Use this when you want ChatGPT to create a complete app without overlapping UI, weak launch instructions, or missing progress states.

Create a complete downloadable local application for this idea: [APP IDEA]. Before creating files, first write a short implementation spec that includes main user goal, core features, non-goals, recommended technology choice, file/folder structure, performance risks, error states, and user acceptance checklist. Then create the actual runnable files. Do not give copy-and-paste code only. Use the best development approach for the app idea. Do not force batch files unless they are the best option or useful as optional launchers. Include clear loading/progress indicators, friendly error handling, a normal launcher when useful, a debug launcher when useful, and a README written for a non-developer. Make the interface clean, modern, polished, evenly spaced, responsive, and easy to use. Avoid overlapping elements.
